# SAM. Transformation OS

A personal, minimal, dark-themed transformation tracker built to log a 17-week journey (May 4 → Aug 31). Designed for one user, built with purpose.

## Features
- **The Plan**: 17 weeks broken down into 5 distinct phases (Re-Entry, Build, Load, Peak, Forge). Includes weekly calendars, strength/cardio plans, and nutrition targets.
- **The Tracker**: A complete logging system powered by local storage to track daily weight, strength progression, running distance, body measurements, and nutrition.
- **Private Access**: Session-based authentication gate.
- **Visuals**: Built with a sleek dark-mode aesthetic, utilizing Recharts for data visualization and a custom Tailwind design system.

## Tech Stack
- Next.js 14+ (App Router)
- React
- Tailwind CSS
- Recharts
- Lucide Icons
- LocalStorage Data Layer
